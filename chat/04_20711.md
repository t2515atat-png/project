1. 회귀·분류·군집 중 무엇을 선택해야 할까?
회귀 선택
네 탐구 질문은 다음과 같지.
기온과 시간대 정보를 활용하면 공공자전거 대여량을 얼마나 정확하게 예측할 수 있을까?

여기서 예측하고 싶은 값은 **자전거 대여량(대)**이야.
- 회귀: 대여량처럼 숫자로 된 값을 예측
- 분류: 데이터를 정해진 종류로 구분
- 군집: 비슷한 특징을 가진 데이터끼리 묶음
따라서 네 탐구에는 회귀 분석이 가장 적합해.
네 탐구의 머신러닝 구조
입력 데이터(X)

기온 + 시간대


회귀 모델 학습 및 예측


예측 결과(Y)

공공자전거 대여량(대)


2. 모델 3개는 무엇을 선정하면 좋을까?
고2 수준에서 원리를 이해하기 쉽고, 서로 다른 방식으로 예측하는 모델 3개를 추천할게.









① 선형 회귀(Linear Regression)
- 데이터의 전반적인 직선 관계를 찾아 예측해.
- 기온과 시간대가 대여량에 미치는 관계를 단순한 식으로 나타내는 모델이야.
- 가장 기본적인 회귀 모델이라 다른 모델과 비교하기 좋아.












② 의사결정나무 회귀(Decision Tree Regressor)
- 기온과 시간대에 따라 데이터를 여러 구간으로 나눠.
- 각 구간에 속한 데이터의 평균 대여량 등을 이용해 예측해.
- 복잡하고 직선이 아닌 관계도 학습할 수 있어.












③ 랜덤 포레스트 회귀(Random Forest Regressor)
- 여러 개의 의사결정나무를 학습시켜.
- 각 나무의 예측 결과를 평균 내어 최종 대여량을 예측해.
- 여러 나무의 결과를 종합하기 때문에 하나의 나무에만 의존하지 않아.



이 세 모델은 모두 회귀 모델이지만 작동 방식이 달라서 비교하기 좋아. 실제 공공자전거 수요 예측 연구에서도 선형 회귀와 의사결정나무, 랜덤 포레스트 등을 비교한 사례가 있어. 
KCI+1

3. 모델 성능은 어떻게 비교할까?
모델을 학습시킨 뒤에는 실제 대여량과 모델이 예측한 대여량을 비교해야 해.

대표적으로 다음 두 지표를 사용하면 돼.
평가 지표	의미	좋은 결과
MAE	실제값과 예측값의 평균적인 차이	낮을수록 좋음
R²(결정계수)	모델이 실제 데이터의 변화를 얼마나 설명하는지	1에 가까울수록 좋음

예를 들어 MAE가 100이라면 예측한 대여량이 실제 대여량과 평균적으로 약 100대 차이 난다는 뜻이야.
